# Bootstrap Icons

Official source: https://icons.getbootstrap.com/
Repository: https://github.com/twbs/icons
Version: 1.13.1
License: MIT, see LICENSE.txt.

The project uses the official local stylesheet Content/bootstrap-icons.min.css and fonts under Content/fonts. The country indicator uses bi-geo-alt-fill. Avatar fallbacks display initials; no default user silhouette is used. All icon artwork is sourced from Bootstrap Icons, not AI generated. The unused SVG sprite has been removed.

Decorative SVG artwork is separate from the icon set and is retained. UI icons use official Bootstrap Icons.
